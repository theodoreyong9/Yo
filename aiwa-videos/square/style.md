# Feuille de style (tout le film)
- **Palette** : fond nuit `#0b0b0f` (60 %), ivoire `#f2f0ea` (30 %, texte), ambre `#ffb347` (10 %, accent unique : un mot ou un chiffre par plan).
- **Type** : Inter Display Black pour les mots (casse normale pour les titres, serrés −0,02 em, énormes ; majuscules espacées seulement pour les petites étiquettes ; titres centrés, sauf les plans « 0 » et « mobile » alignés à gauche à côté de leur illustration) ; Liberation Mono pour les compteurs et l'adresse. Deux familles, deux graisses.
- **Mouvement** : même easing (ease-out expo), entrées 0,25–0,6 s, décalage 60–100 ms entre mots. Texte par masque ou par chute. Caméra : zoom/dérive lent sous 8 %. Transitions : push et iris, flash sur le coup de grosse caisse seulement.
- **Son** : impulsion ~120 bpm, accent à chaque coupe, riser avant la révélation, **silence d'un temps avant « Dis salut. »** ; voix courte, uniquement sur les temps forts ; la musique baisse sous la voix (`--duck=light`).
- **Grade** : grain léger 0,02 + vignette 0,25 ; pas de bloom fort (le noir ne doit pas virer au violet).
